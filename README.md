# ربات آپلودر با لینک اختصاصی + جوین اجباری

## چیکار می‌کنه؟
- تو (ادمین) فیلم/فایل رو برای ربات می‌فرستی
- ربات فایل رو توی یه کانال خصوصی ذخیره می‌کنه و یه لینک اختصاصی می‌سازه
- هر کسی روی لینک بزنه، اول باید عضو کانال(های) اجباری بشه، بعد فایل براش ارسال میشه
- از طریق `/panel` می‌تونی فایل‌ها رو ببینی/حذف کنی و کانال‌های جوین اجباری رو مدیریت کنی

## مرحله ۱: نصب پیش‌نیازها

```bash
pip install -r requirements.txt
```

## مرحله ۲: ساخت ربات در بات‌فادر

اگه قبلاً ساختی، توکنش رو داری. اگه نه:
1. توی تلگرام برو به `@BotFather`
2. `/newbot` بزن و اسم و یوزرنیم انتخاب کن
3. توکن رو کپی کن

## مرحله ۳: پیدا کردن آیدی عددی خودت

برو به `@userinfobot` و پیام بده، آیدی عددیت رو بهت می‌ده.

## مرحله ۴: ساخت کانال ذخیره‌سازی (خصوصی)

1. یه کانال خصوصی جدید بساز (فقط برای ذخیره فایل‌ها، هیچکس دیگه عضوش نباشه)
2. ربات رو به عنوان **ادمین** به این کانال اضافه کن
3. برای گرفتن آیدی عددی کانال: یه پیام توی کانال بفرست، بعد فوروارد کن به `@getidsbot` — یه عدد منفی مثل `-1001234567890` می‌ده

## مرحله ۵: پر کردن config.py

فایل `config.py` رو باز کن و این مقادیر رو جایگزین کن:

```python
BOT_TOKEN = "توکنی که از بات‌فادر گرفتی"
ADMIN_ID = 123456789          # آیدی عددی خودت
STORAGE_CHANNEL_ID = -1001234567890   # آیدی کانال ذخیره‌سازی
BOT_USERNAME = "MyUploaderBot"        # یوزرنیم ربات بدون @
```

## مرحله ۶: اجرا

```bash
python bot.py
```

## نحوه استفاده

### آپلود فایل جدید
1. توی چت ربات `/panel` بزن
2. روی «📤 آپلود فایل جدید» بزن
3. فیلم/فایل رو بفرست
4. ربات لینک اختصاصی رو بهت می‌ده — همین لینک رو به کاربرها بده

### حذف فایل
`/panel` → «📁 لیست فایل‌ها / حذف» → روی فایل موردنظر بزن

### افزودن کانال جوین اجباری
1. ربات رو **ادمین** کانالی که می‌خوای اجباری کنی، بکن
2. `/panel` → «🔒 مدیریت جوین اجباری» → «➕ افزودن کانال»
3. یه پیام از اون کانال فوروارد کن برای ربات

### حذف کانال جوین اجباری
`/panel` → «🔒 مدیریت جوین اجباری» → روی ❌ کنار اسم کانال بزن

## نکات مهم

- ربات باید توی **کانال ذخیره‌سازی** و توی **همه کانال‌های جوین اجباری** ادمین باشه، وگرنه کار نمی‌کنه
- برای اجرای ۲۴ ساعته، بهتره روی یه سرور (VPS) با `screen` یا `systemd` یا `pm2` اجراش کنی تا با بستن گوشی/سیستم قطع نشه
- دیتابیس (`bot_data.db`) کنار فایل‌های ربات ساخته میشه؛ ازش بک‌آپ بگیر

## اگه گیر کردی
- خطای "Chat not found" → یعنی آیدی کانال اشتباهه یا ربات هنوز عضو/ادمین نشده
- خطای "Not enough rights" → ربات باید ادمین کانال باشه با دسترسی ارسال پیام
